# TinyFish Agent OS

Multi-agent web automation platform built for the TinyFish $2M Hackathon. Transforms complex web workflows into autonomous AI agents that do real work on live websites.

## 🎯 Problem

Businesses waste thousands of hours on repetitive web tasks - manual company research, vendor comparison, compliance monitoring, and competitor analysis. The web wasn't built for AI agents.

## 💡 Solution

TinyFish Agent OS provides 7 specialized agents that navigate real websites, extract structured data, and execute multi-step workflows autonomously.

## 🤖 Agents

1. **🎯 SDR Lead Agent** - Automated sales prospecting and outreach
2. **🔍 Due Diligence Agent** - Investment research and company analysis
3. **🛡️ Compliance Monitor** - Track pricing, terms, and policy changes
4. **📦 Procurement Agent** - Vendor comparison and RFQ automation
5. **👥 Talent Intel Agent** - Competitor hiring pattern analysis
6. **✈️ Travel Booking Agent** - Flight and hotel comparison shopping
7. **⚡ Custom Agent** - Define any web automation task

## ✨ Features

- **Real Browser Automation** - Navigates dynamic websites with TinyFish API
- **Batch Processing** - Process 50+ URLs simultaneously
- **Scheduler** - Automate recurring tasks
- **Change Detection** - Track and alert on changes
- **CSV Export** - Export results for team collaboration
- **Email Alerts** - Notify stakeholders automatically
- **Stealth Mode** - Bypass anti-bot protection
- **Proxy Support** - IP rotation for reliable access

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/tinyfish-agent-os.git
cd tinyfish-agent-os
```

2. Start local server:
```bash
python3 -m http.server 8000
```

3. Open in browser:
```
http://localhost:8000/tinyfish-final.html
```
